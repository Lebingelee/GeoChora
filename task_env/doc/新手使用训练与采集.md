# TaskEnv 训练与采集

本文面向使用现有 TaskEnv 环境进行强化学习、SB3 训练或轨迹采集的用户。安装和最短运行命令请先看 [README Quickstart](../README.md)。

## 1. 单环境交互

~~~
from task_env import make_env

env = make_env("pendulum-v1", config={"runtime": {"backend": "cpu"}})
try:
    observation, info = env.reset(seed=73)
    for _ in range(10):
        observation, reward, terminated, truncated, info = env.step(
            env.action_space.sample()
        )
        if terminated or truncated:
            observation, info = env.reset()
finally:
    env.close()
~~~

reset 返回 observation、info；step 返回 observation、reward、terminated、truncated、info。动作和观测的结构、shape、dtype 以环境的 Gymnasium space 为准。

## 2. 并行环境与 SB3

raw parallel environment 保留结构化 observation/action tree，并要求 batch 维位于首维：

~~~
import numpy as np
from task_env import make_parallel_env

env = make_parallel_env(
    "pendulum-v1",
    num_env=8,
    backend="cpu",
    execution="remote",
)
try:
    observation = env.reset()
    action = {"torque": np.zeros((8, 1), dtype=np.float32)}
    observation, reward, done, infos = env.step(action)
finally:
    env.close()
~~~

execution="local" 将环境保留在当前进程，适合调试和快速验证；execution="remote" 使用独立 simulator worker，适合与 learner 隔离。远程环境使用 spawn，不应在已初始化 Taichi/CUDA 状态后改用 fork。

接入 SB3 时使用 flatten wrapper 作为 learner 边界：

~~~
from stable_baselines3 import PPO
from task_env import make_parallel_env
from task_env.utils import SB3FlattenVecWrapper

raw_env = make_parallel_env("pendulum-v1", num_env=8, backend="cpu", execution="remote")
env = SB3FlattenVecWrapper(raw_env)
try:
    model = PPO("MlpPolicy", env, n_steps=5, batch_size=40, n_epochs=1, device="cpu")
    model.learn(total_timesteps=120)
finally:
    env.close()
~~~

## 3. RSL-RL PPO

统一入口为 task_env.script.rl.rsl_ppo。`--env-id` 必须显式指定，并且只能选择在 `PARALLEL_ENV_REGISTRY` 中登记、具备相应 learner action/observation contract 的 task；入口不会默认选择训练目标。

`env-config` 是公共 YAML overlay；省略时使用所选 task 的默认配置。`render` 与 `hard-render` 是可选并行展示路径，不改变 PPO 的 action/reward/done 契约。Go2 task、agent、RSL profile 和独立评估工具已在 S3 退休；历史运行请从不可变 v1.0.0 恢复，旧 UID 不会被替换成其他任务。

## 4. 轨迹和 H5

跨任务的公共记录入口位于 task_env.script.trajectory.record：

~~~
PYTHONPATH=GeoPhys/src:. python -m task_env.script.trajectory.record \
  --env-id pick-cube-v1 \
  --output temp_outputs/task_env/trajectories/pick_cube.h5 \
  --no-render
~~~

录制器只消费 public reset/step/info/metadata，不读取 solver private state。H5 的基本长度关系为：

~~~
len(observation) - 1 == len(action) == T
~~~

Panda trajectory 可以继续使用 convert 和 replay；Pendulum、双轮车等 non-arm action 不应套用 Panda 的 8D action layout。
