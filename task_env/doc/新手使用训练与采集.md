# TaskEnv 训练与采集

当前可运行命令、资源限制、输出和 capability 范围以仓库根目录的
[开发工作流指南](../../examples/README.md)为准。仓库没有 editable-install
元数据；从仓库根目录使用 GeoChora 依赖环境并设置 `PYTHONPATH=GeoPhys/src:.`。

## 单环境与当前参考任务

```python
from task_env import make_env

env = make_env("pendulum-v1", config={"runtime": {"backend": "cpu"}})
try:
    observation, info = env.reset(seed=73)
    observation, reward, terminated, truncated, info = env.step(
        env.action_space.sample()
    )
finally:
    env.close()
```

当前选中的 manipulation UID 是 `pick-cube-p16-reference-v1` 与
`nut-assembly-outcome-reference-v1`。通过根目录 `examples/tasks/` 执行；
NutAssembly 只开放受 guard 约束的 `step_expert()`。成功的物理任务结果、
Expert lifecycle 与录制是否完成分别报告。

## 并行环境与学习

`make_parallel_env` 保留结构化 observation/action tree，batch 维在首维；
SB3 flatten 仍由 `SB3FlattenVecWrapper` 负责。当前 bounded learning smoke
使用 Pendulum、CPU 和 `merged_scene`，并委托给已有的 SB3 PPO runner：

```bash
PYTHONPATH=GeoPhys/src:. python examples/learning/pendulum_sb3.py \
  --output-dir workspace/maintenance/pendulum-sb3-smoke-01
```

这只验证一轮训练 wiring、cleanup 和输出，不证明收敛或通用训练 qualification。
RSL-RL CLI 必须显式传 `--env-id`，并通过 task 并行注册及 learner contract
准入；Go2 已退休，不会替换为 PickCube 或 NutAssembly。

## 录制和离线检查

```bash
PYTHONPATH=GeoPhys/src:. python examples/recording/record_expert.py \
  --env-id pick-cube-p16-reference-v1 --provider mujoco --seed 31 \
  --output workspace/examples/pickcube-mujoco.h5

PYTHONPATH=GeoPhys/src:. python examples/recording/inspect_h5.py \
  --input workspace/examples/pickcube-mujoco.h5
```

录制使用现有 canonical H5 contract；离线检查验证 schema、logical/numeric
storage integrity 与 `T+1` boundary，不代表 replay 或 D0 reconstruction。旧
H5 replay 需显式使用 historical route；selected-source reexecution 是单独路径。

## Rendering 与 Camera

当前 bounded native rendering smoke 覆盖 Pendulum × GeoPhys CPU × scalar
TaskEnv × rasterizer RGB，以及 `merged_scene` batch × rasterizer RGB。它不覆盖
Flora、selected manipulation camera observation，或 Physics × Renderer
interoperability。
`CameraSpec`、Camera、Renderer Registry、Flora 与 rasterizer contract 保留。
旧的 `render_single` CLI、PickCube `camera.static`/`camera.bound` 及 lighting
probe 显式 retired；当前 scalar Pendulum 示例使用公开 `make_env`。恢复信息见
`docs/module/task_env/p2_0_s4_5_b_source_recovery.json`。

完整 import 路径和迁移说明见 [API examples](api/examples/index.md) 与
[migration](api/appendix/migration.md)。
