# TaskEnv 新手使用、采集与训练

从[安装与启动](../../docs/module/task_env/v2.1.1/guides/installation-and-start.md)选择实际 Python、Core、GeoPhys 源码和 provider。该指南列明 MuJoCo 依赖冲突、可选 renderer 与未验证路线。训练不属于首次单环境闭环；仓库没有 root editable-install metadata。

## 一个单环境

准备已有 GeoPhys CPU 环境后，`examples/start.py` 的 `pendulum-v1`、`--renderer none` 路线重置一次、执行一个零扭矩 transition 并 close。其完整路径参数见安装指南；当前维护版本尚未做该入口 native 验证。

当前直接 factory 签名为 `make_env(uid, *, config=None, render_mode=None, **kwargs)`。例如（片段未在本维护版本运行）：

```python
import numpy as np
from task_env import make_env

env = make_env("pendulum-v1", config={"execution": {"physics_provider": "mujoco", "physics_backend": "cpu", "deployment": "in_process"}})
try:
    observation, info = env.reset(seed=73)
    observation, reward, terminated, truncated, info = env.step(
        {"torque": np.zeros(1, dtype=np.float32)}
    )
finally:
    env.close()
```

Pendulum 使用单个 torque，TwoWheel 使用两个 wheel torque；这两者的 state/action 规格不同于 Panda。每次使用真实 `action_space`、`observation_space` 和 task metadata 检查实际 shape、dtype、单位与边界。`reset` 返回 `(observation, info)`；`step` 返回五元组。终止或截断后要 reset；`close()` 负责释放自有资源。错误或 fault 不应被当作正常完成。

## Selected task 和记录

选中的 UID 是 `pick-cube-p16-reference-v1` 和 `nut-assembly-outcome-reference-v1`，旧 UID 在当前 factory 中明确退休。selected 使用 `execution`、`episode` 和 task 可接受的配置，render 能力以版本矩阵中的实际路线为准；[NutAssembly](../../examples/tasks/nut_assembly.py)和[PickCube](../../examples/tasks/pick_cube.py) 的普通CPU示例均由调用方持有 Solution，经 `act → step(action) → observe` 执行。Nut 的合法普通 pose 可以直接传入；Solution proposal 必须携带来源边界和控制请求，不能绕开 guard。外部动作与旧 Expert 模式不能在同一 episode 混用，任务成功和 Solution 完成各自报告。

当前 selected 的录制入口为 `env.start_recording(path)` 和 `env.finish_recording(reason)`，必须在 reset 后、首个 transition 前开始；路径已存在会失败。也可使用 [`examples/recording/record_expert.py`](../../examples/recording/record_expert.py)，再用 [`inspect_h5.py`](../../examples/recording/inspect_h5.py) 独立读取。`T` 条 transitions 对应 `T+1` 个 boundaries；reader 验证存储、schema 和完整性，不代表 replay、任务成功或 D0 恢复。历史 H5 replay 与当前 selected 同源重执行是不同入口；旧 PickCube 历史执行需要对应冻结源码。

## 采集普通动作并独立读回

以下实际使用 MuJoCo CPU 和 Nut seed19；动作以 reset TCP 为中心，不从 Solution 获取。文件必须不存在；`finish_recording` 写完成的 transition，`finally` 释放 Env，reader 离线核查。

```python
from pathlib import Path
import numpy as np
from task_env import make_env
from examples._common import load_recording_summary

path = Path('nut-random.h5')
rng = np.random.default_rng(1902)
env = make_env('nut-assembly-outcome-reference-v1', config={
    'execution': {'physics_provider': 'mujoco', 'physics_backend': 'cpu', 'deployment': 'in_process'},
    'episode': {'horizon': 100},
})
try:
    obs, info = env.reset(seed=19)
    pose = env.state.pose_world['panda-v1/ee']
    base, quat = np.asarray(pose.position), np.asarray(pose.quaternion_wxyz)
    env.start_recording(path)
    for i in range(32):
        delta = np.zeros(3) if i < 4 else rng.uniform(-.002, .002, 3)
        action = np.r_[base + delta, quat, 1. if i < 4 or i % 2 == 0 else -1.]
        obs, reward, terminated, truncated, info = env.step(action)
        if terminated or truncated:
            break
    env.finish_recording('external_stop')
finally:
    env.close()
summary = load_recording_summary(path)
print(summary['transitions'], summary['boundaries'], summary['action_origins'])
```

本代码与 7c002 教程实测的输入规则一致；该实测读回 32/33、普通来源、未评估 Solution。Task success、Solution done/failed 和 H5 完整性须分别读取，不能从 `expert_identity` 或旧 `planned_action` 推断完成。Solution 采集改用原任务 Solution 的 `reset → act → step → observe`，不能与普通 action 在一个 episode 混用。[H5 说明](api/recording/h5_schema.md)区分各 schema。

## Render、并行和学习

已有 scalar Pendulum / GeoPhys CPU / rasterizer RGB 与其他 Task 渲染是不同能力。窗口或 RGB `render()` 不等于 agent observation 中的相机图像；7c002 的 GeoPhys Nut Rasterizer 首帧因 Scene/source 条件失败，不能外推为其他路线结果。Flora 的 `FLORA_ROOT` 和相关运行边界见[安装指南](../../docs/module/task_env/v2.1.1/guides/installation-and-start.md)。

旧 `make_parallel_env` 与历史 SB3 smoke 保留；G06 已有 Pendulum/PickCube 的有界 device batch，旧 SB3/RSL wrapper 不因此支持 same-step，单 slot 也不证明任意 batch。训练入口和示例见[开发工作流](../../examples/README.md)，训练结果不等于收敛或 qualification。任务开发从[现有声明式示例](自定义任务构建指南.md)开始；接口细节见 [API index](api/index.md)。
