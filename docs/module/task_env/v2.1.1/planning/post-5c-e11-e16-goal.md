### 2. 清理可重建的历史运行自有缓存

复用已形成的Kit、DerivedDataCache、shader、Taichi、OptiX等候选及归属检查。对已确认的可重建缓存，执行前核对实际使用、路径／类型、挂载和权限等必要边界；不新增逐文件内容审计、缓存备份或历史SDK重建。

当前活动缓存、全局SDK缓存、第三方source原件、已安装资产和其他项目内容排除。缓存归属存在具体疑点时，仅该项列例外，不拖住其他已确定范围。

102个阶段目录此前约23.11 GB，其中运行缓存约11.56 GB、重复网格分配量约9.78 GB。上述数值用于确定工作优先级；估算剩余约1.77 GB不作为强制空间上限。最终按实际保留集和完整统计范围测量。
