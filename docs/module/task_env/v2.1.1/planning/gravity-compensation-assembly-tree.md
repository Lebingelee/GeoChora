# 基于装配树的重力补偿范围（设计提案）

状态：2026-11-06维护者已确认采用此设计方向，并将“裸臂＋夹爪的新Panda类、空载末端精度、夹爪控制和原Solution复用”纳入[阶段4安排](stage4-assembled-panda.md)。当前通用选择仍未实现或验证；已实现并接收的选项仅支持来源绑定的Panda一体手，不支持自定义子树或固定附件。此文不改变3b原N08失败或已接收范围，不重开G03。当前实现见[003 Sol复审](../maintenance/reviews/20261106_3b_attempt003_sol_review.md)。

## 目标与语义

将补偿对象定义为**明确选择的、相对于所控机械臂根部连通的刚体集合**，而非按品牌或末端设备类型硬编码。集合可覆盖纯机械臂、集成夹爪，也可覆盖通过明确固定连接装配的其他夹爪或灵巧手。每个被选择的运动刚体贡献其质量及质心产生的重力；不选取的物体、桌面和接触载荷不因为碰撞或抓取而自动纳入。独立载荷是否能够被显式选择，应由后续合同规定，不应默认推断。

新装配无需与原一体Panda的物性或拼接方式一致。质量／质心／关节状态用于计算新装配自己的重力贡献；运行验收看声明可行域内空载TCP跟踪和夹爪控制是否满足任务需要。不能把自身模型绑定解释成与旧机器人逐项等价，也不将旧TCP安装偏移强加给新装配。

树上的非固定关节需要其真实位置；被驱动手指的重力也可能要求手指执行器补偿，不能只计算七个臂关节就声称整个装配获得补偿。若某些自由度无法表达所需补偿，须在启用前拒绝或明确报告未覆盖范围，不能静默丢弃。固定基座假设与移动基座动力学应分别定义。

## 来源与选择合同

1. `LogicalAssembly` 给出实体成员，并不单独证明这些成员形成物理树；各实体内部连接来自 `SceneDefinition` 中的关节及固定帧，跨实体连接须来自经过来源验证的 `FixedAttachmentPlanV1` 或将来等价的可验证连接合同。当前固定附件合同本身仍有特定手部的限制，不应据此宣称通用附件已经可用。
2. 请求应显式指定被控根、目标实体／连通子段和可选分支。解析器验证成员身份、每条父子连接、根可达性、无环、没有遗漏中间刚体，也不自动纳入未选分支。选择结果应绑定场景、装配、附件、来源与选择内容的身份摘要，并保留逐体列表供审计。
3. 逐体质量、质心、坐标系与关节轴来自所选新装配自身来源，并与该次provider模型对应；这不是对原Panda的物性相等检查。沿已有source／model owner处理实际缺项与映射，不另造完整惯量／摩擦等价对照活动。
4. 以实际基座姿态将世界重力转换到正确坐标系，按所选刚体和当前关节状态计算广义重力；静态势能梯度测试提供一般公式证据，有限的旋转或姿态实验只能覆盖所测样本。
5. 分别核对已有驱动、provider 和控制层是否已加入同一重力贡献；不可确定时拒绝叠加。逐执行器说明所需贡献、应用方式、目标限幅和力矩／力限幅；应保留原动作及反馈的身份。真实七关节力反馈若无正式公开接口，应标注不可用，不用诊断 solver 内部访问冒充该接口。

## 实施与验证的阶段边界

当前Panda路线已有有界来源绑定和回执，集合仍固定。下一步在4a定义新Panda类、配置选择与连通子段及自身模型；4b复用控制器并实现／验证补偿贡献、空载跟踪和夹爪；4c用两任务原Solution完成代表成功。两正式任务必须消费新类，不以候选来源导入成功代替。三后端原控制门不变，新增装配首个实际路线为MuJoCo CPU；更广外接夹爪／灵巧手能力逐项另定，不成为本轮首个组合的隐含前置。

本轮验收聚焦新装配的正确连通／质量映射、任务所需空载跟踪、现有夹爪控制、实际补偿贡献及两任务成功；默认关闭兼容和真实驱动约束沿受影响路径核对。任务精度和可行域在4a包冻结，不能用旧3b实验误差替代需求。纯臂／任意手／旋转或移动基座／所有拒绝变体是后续扩展参考，不追加成阶段4首个装配的全排列矩阵。每个provider按实际证据标范围，单一MuJoCo实验不推广为GeoPhys／Isaac结果。
