# 基于装配树的重力补偿范围（设计提案）

状态：2026-11-06维护者已确认采用此设计方向；通用选择合同尚待细化，功能尚未实现或验证。当前已实现的选项仅支持来源绑定的 Panda 一体手，不支持自定义子树或固定附件。此文不改变 3b 原 N08 判据或其失败身份，通用装配扩展不追加为原3b出口。当前有界补偿与后续范围见[Sol复审](../maintenance/reviews/20261106_3b_attempt002_sol_review.md)。

## 目标与语义

将补偿对象定义为**明确选择的、相对于所控机械臂根部连通的刚体集合**，而非按品牌或末端设备类型硬编码。集合可覆盖纯机械臂、集成夹爪，也可覆盖通过明确固定连接装配的其他夹爪或灵巧手。每个被选择的运动刚体贡献其质量及质心产生的重力；不选取的物体、桌面和接触载荷不因为碰撞或抓取而自动纳入。独立载荷是否能够被显式选择，应由后续合同规定，不应默认推断。

树上的非固定关节需要其真实位置；被驱动手指的重力也可能要求手指执行器补偿，不能只计算七个臂关节就声称整个装配获得补偿。若某些自由度无法表达所需补偿，须在启用前拒绝或明确报告未覆盖范围，不能静默丢弃。固定基座假设与移动基座动力学应分别定义。

## 来源与选择合同

1. `LogicalAssembly` 给出实体成员，并不单独证明这些成员形成物理树；各实体内部连接来自 `SceneDefinition` 中的关节及固定帧，跨实体连接须来自经过来源验证的 `FixedAttachmentPlanV1` 或将来等价的可验证连接合同。当前固定附件合同本身仍有特定手部的限制，不应据此宣称通用附件已经可用。
2. 请求应显式指定被控根、目标实体／连通子段和可选分支。解析器验证成员身份、每条父子连接、根可达性、无环、没有遗漏中间刚体，也不自动纳入未选分支。选择结果应绑定场景、装配、附件、来源与选择内容的身份摘要，并保留逐体列表供审计。
3. 逐体质量、质心、坐标系与关节轴必须来自可核验的来源，并与实际装配后 provider 模型对应；缺失、重复、不同步或无可验证映射时拒绝开启。拓扑选择本身并不能证明惯性数据或驱动适配已经正确。
4. 以实际基座姿态将世界重力转换到正确坐标系，按所选刚体和当前关节状态计算广义重力；静态势能梯度测试提供一般公式证据，有限的旋转或姿态实验只能覆盖所测样本。
5. 分别核对已有驱动、provider 和控制层是否已加入同一重力贡献；不可确定时拒绝叠加。逐执行器说明所需贡献、应用方式、目标限幅和力矩／力限幅；应保留原动作及反馈的身份。真实七关节力反馈若无正式公开接口，应标注不可用，不用诊断 solver 内部访问冒充该接口。

## 实施与验证的阶段边界

先为当前 Panda 路线建立来源绑定和可审计回执；当前实现已具备一个有界版本，但其刚体集合仍由 Panda 来源固定，不能接受用户自定义树。接下来需要独立设计并验证通用树选择、跨实体质量映射、各自由度驱动能力以及运行时刷新；只有这些环节完整连通，才可宣称支持具体外接夹爪或灵巧手。对尚不支持的组合应明确拒绝。

验收应覆盖：默认关闭和原行为逐边界等价；纯臂／一体手／真实外接固定夹爪／带多关节手的有效组合；漏中间节点、断链、环、错误来源、未选择外物和不可驱动自由度的拒绝；旋转基座的解析势能交叉检查及代表性真实闭环；首个物理子步和稳态分别测量；目标／力限幅和已有补偿冲突。每个 provider 单独验证，不将单一 MuJoCo 实验推广到 GeoPhys 或 Isaac。
