# E15 集中处置方案：独立只读复核

独立复核范围是[最终保留表](20261114_e15_final_retention_conclusions.md)、[最终处置方案](20261114_e15_final_disposition_proposal.md)、清单和执行入口；不是 U4／U5 重审，也不是删除授权或项目接收。

- G01～G05 与优化六行没有发现改变 U5 既有接收结论的矛盾；N08、COM、R05c、4b 源码、SDK 关闭及 T19 同次联合证据限制保持。独立复核 816 个 stage 对象 SHA／大小；实施方补核整个最终选择及 13 个 supporting source 索引共 1,021 对象。
- 独立遍历 103 个根，76,179 条普通文件／链接及 24,661 个目录与终稿身份和链接目标一致；两个例外和祖先须保留。285 套网格共 19,095 路径、每套 67 名称及 SHA 映射一致，67 个 U5 对象和 12 套包内素材布局已核对。原 19,095 文件本轮未逐个重算 SHA。
- 无候选与共享锁或 U5 已选 stage 对象的路径／inode 冲突；586 个只读目录均为本人拥有、模式 `0555`。旧 overlay 只删除链接本身，映射不保证旧环境重放。147 个待退役临时副本与映射的 U5 对象分别重算 SHA 一致；旧 retained manifest 在副本移除后须通过 scratch 映射寻找对象。
- 首次复核发现检查模式覆写收据、信号与模式恢复、scratch 执行门、日志持久化及 U5 索引身份问题；实施方已修复并复核。独立重跑 6 项隔离集成测试与 5 项原语测试通过，含临时真实 flock／双路径、漂移、锁替换、日志失败、SIGTERM、SIGKILL、例外与人工模式恢复。合成保护输入及 pins 为空、U5 verifier 为替身；真实范围的 `--check` 单独点时通过。

在已审查的代码与测试范围内，没有发现新的可具体复现、必须先修的真实执行阻断。此结论不证明不可见／非协作进程不存在，不证明全部崩溃时序或历史环境可复现。中断必须手工恢复和逐项对账；执行仍以维护者具体授权、锁内重检及清理后独立核验为前提。未执行真实删除或 native。
