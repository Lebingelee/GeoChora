## 调用与 owner

四任务 `make_env → 共同配置与 TaskBuildRequest → SourceBoundTaskBuilder → Task intent + Robot declaration → source adapter → Controller binding → RuntimeSession → Env reset/submit/step/close`。PickCube 在请求内选择受限 MJCF 或 USD source strategy；Nut 使用其任务物体声明与 assembly；Pendulum／双轮车以自身 Robot 与 effort group 编译。任务不负责 provider 进程或 renderer 推进；一个场景 interval 由共同提交 owner 和选定物理 session 推进。各 source 保有 closure 与 snapshot lease；typed state 和控制反馈具有同一 boundary／clock；renderer 只消费状态，borrowed 不销毁物理资源，独立 visual source 由 renderer 释放。Recorder 记录提交和 native ACK，不把请求/ACK冒称独立测力。
