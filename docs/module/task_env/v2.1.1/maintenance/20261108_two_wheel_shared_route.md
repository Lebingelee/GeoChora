# Two-wheel shared physical route

The two-wheel source is referenced once through the same declared subject compiler, direct-effort Controller and selected RuntimeSession used by Pendulum. Its two ordered channels remain left and right wheel hinge torques bounded to ±1.5 N·m; pitch is observed, not commanded. GeoPhys CPU and MuJoCo CPU support is limited to the tested fixed-anchor source and requires independent review. `rgb_array` remains a GeoPhys CPU observer and task RGB is a separate construction-time selection. The `human` mode currently admits construction but visible presentation is unavailable and `render()` raises `RenderUnavailableError`; prior component UI behavior is not yet restored or verified on the shared route. No general free-body reset, Isaac execution or complete renderer matrix is claimed.
