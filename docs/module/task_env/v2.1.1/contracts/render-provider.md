# Core ↔ render adapter 协议草案

状态：`DRAFT_FOR_DISCUSSION`；1d 冻结。涵盖窗口展示、图像采集、同步 observation，复用既有 render／camera owner。Flora 不在本版实施范围。

## 三类完成目标

| 目标 | 输入与输出 | 独立完成条件 |
| --- | --- | --- |
| 窗口展示 | 当前场景、观察相机、窗口／事件请求 | 用户可配置相机并观察，窗口生命周期正确；不以此证明 RGB observation |
| RGB 采集 | 相机、分辨率、状态身份和采样请求 | 返回规格明确的真实图像，标定及采样时间可核实 |
| 任务 observation | 环境固定的相机观测契约 | reset／step 自动协调采样和同步，调用方无需额外 `.render()` |

对外沿用 Gymnasium 熟悉的 render_mode／metadata／render／close 习惯。具体 reset 扩展和模式映射见后续 API 文档；不得预先声称兼容任意 Gymnasium wrapper。

## 场景准备与数据流

| 环节 | Core／公开场景数据提供 | Render adapter 返回 |
| --- | --- | --- |
| 能力与准备 | 视觉几何、材质、实体映射、相机／灯光、所选 physics 及可复用 native 绑定 | 接受的格式、设备、输出／窗口能力、前置资源需求和拒绝原因 |
| 动态更新 | 刚体变换、变形几何／粒子／体积扩展、状态与拓扑代次、同步凭据 | 已消费状态、更新完成情况、转换成本及是否需要几何重建 |
| 展示／采样 | 目标状态、相机、输出及截止／完成要求 | 图像或展示结果、实际相机／时间／状态身份、完成凭据、失败或丢帧 |
| 重建／关闭 | 生命周期操作及原生绑定代次 | 旧缓存／数据失效和自有资源释放；共享资源不被重复关闭 |

这是一条由既有 Core／provider 公共接口承接的场景数据路径，不预定新增 SceneDataManager 或镜像物理状态。Native renderer 可通过明确绑定复用模型／场景；独立 renderer 可消费公开快照。相同接口允许不同传输方案，不能强迫零复制或全部转 CPU。

## 共享资源与独立选择

Physics 和 renderer 的需求必须在原生构建前汇总，明确应用、scene／stage、模型、设备、context、窗口和工作进程的唯一 owner。共享模型可只做公开 kinematics／visual 更新，不得在 renderer 里再推进第二套物理。

Renderer 独立选择是能力允许的组合选择；不能由配置字段推断任意配对可运行。每条组合报告实际 physics、renderer、模型来源、格式、设备、传输及限制。原生硬绑定也是合法结果，拒绝不支持的组合。

## 相机与输出

观察窗口相机与任务相机默认分别配置。鼠标拖动观察窗口不改变 Agent observation；需要共用相机时显式选择并记录其对任务观测的影响。任务相机数量、输出规格和语义在环境构建后固定；不同后端／renderer 必须保留这些需求。

相机契约至少说明命名、挂载实体／外参、坐标约定、投影／内参、分辨率、裁剪范围和采样周期。RGB 说明通道顺序、shape、dtype、颜色／数值范围、设备及数据有效期。窗口大小不隐式更改任务图像尺寸。

v2.1.1 交付 RGB；Depth、分割保留独立类型扩展，不自动增加它们的原生验收。软体／绳索／流体需要的几何更新及拓扑变化有类型和能力边界，不由仅支持刚体变换的 renderer 冒充支持。

## 同步与失败

首版同步 observation 采用明确的任务边界：`reset` 首帧反映本轮初始化；`step` 的图像反映约定的该步状态。1d 选择具体调度和同步策略，不能用前一 episode 的帧或未声明的一帧延迟补位。

Native 初始化／预热如需要物理推进，必须显式记账，不计为用户 transition，也不能隐藏改变 reset 结果。重复 `.render()`、窗口事件处理或相机采样不能自行推进任务物理时间。原生 App update 若会推进物理，adapter 必须提供可控路径或拒绝该模式。

必需相机失败不能返回看似有效的零图或旧帧；由 Core 报告失败并保护 transition。仅观察窗口关闭的行为与任务图像失败分开确定：建议停止展示，保留已独立绑定的采集；若原生生命周期不可分，明确限制。失败、重复 close、重建后旧相机引用均需验证。

同一 renderer 的同步身份和场景对应是验收项；不同 renderer 之间不要求像素逐点等价。实际首批与跨组合在 1a/1d 冻结，5a–5c 执行。
