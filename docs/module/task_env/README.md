# TaskEnv versions

TaskEnv is the sole GeoChora Core owner for task construction, configuration, execution lifecycle, observation/action contracts, recording, and evaluation. Use the documentation for the exact source version being investigated:

- [v2.1.0 — local draft candidate](v2.1.0/README.md): current API, configuration, bounded capabilities, and migration notes.
- [v2.0.0 — frozen source snapshot](v2.0.0/README.md): historical contracts extracted from the exact v2.0.0 tag.
- [v1.1.0 — published release](v1.1.0/README.md): original release contracts, matrix, and recovery evidence.
- [v1.0.0 — historical Phase I baseline](../../releases/v1.0/README.md).

The root of this directory is a version index only. Current contracts are maintained once under v2.1.0; historical pages retain their original scope and evidence. A newer version does not silently promote a historical bounded result or overwrite its decision.
