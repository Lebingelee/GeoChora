# TaskEnv versions

TaskEnv is the sole GeoChora Core owner for task construction, configuration, execution lifecycle, observation/action contracts, recording, and evaluation. Use the documentation for the exact source version being investigated:

- [v2.1.1 — protocols and staged implementation](v2.1.1/README.md): seven stages / twenty-two substages for Core, physics and render protocols, control, synchronized RGB, reset switching and parallel execution. G01 and G02 have bounded acceptance; the pre-stage3 lifecycle migration and bounded core closeout are accepted with explicit unverified routes and deferred cleanup; G03–G07 have not started.
- [v2.1.0 — source baseline and candidate closeout records](v2.1.0/README.md): source-versioned API, configuration, bounded capabilities, and migration notes. The local v2.1.0 tag resolves to `fd03817c9f6ef8ce9fd68c1db30125efda68e1c8`; remote publication was not rechecked for the v2.1.1 planning documents.
- [v2.0.0 — frozen source snapshot](v2.0.0/README.md): historical contracts extracted from the exact v2.0.0 tag.
- [v1.1.0 — published release](v1.1.0/README.md): original release contracts, matrix, and recovery evidence.
- [v1.0.0 — historical Phase I baseline](../../releases/v1.0/README.md).

The root of this directory is a version index only. Implemented baseline contracts and evidence remain under v2.1.0; proposed v2.1.1 contracts are maintained once under v2.1.1 with explicit draft status. Historical pages retain their original scope and evidence. A newer version does not silently promote a historical bounded result or overwrite its decision. Old candidate-state wording records its original closeout context and does not establish today's tag or remote Release status.
