# v2.0.0 known limitations

- The tag is a frozen source snapshot; this repository does not establish a publication date or separate acceptance event for it.
- The tag annotation says it grants no new Formal Qualification.
- Provider and asset identities are pinned in the tagged tree, but a gitlink is not proof that an arbitrary checkout can fetch or run the provider/assets.
- Use only the v2.0.0 versioned contracts for tag-era behavior. v2.1.0 fixes, source-bound integration, and test results do not apply retroactively.
- Task, provider, backend, source, renderer, and recording combinations outside the tag's own evidence remain unverified.
