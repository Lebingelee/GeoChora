# 资产材质创建与贴图后处理

本 skill 与 `asset-creation`、`scene-orchestration` 同级安装。材质制作需要 Blender，最终检查需要 Isaac Sim；生图工具及可复用 PBR 由接收方提供。历史案例是方法摘要，不依赖原项目的实验目录。

## 1 职责与适用范围

负责目标表面的材质制作、自然变化、贴图后处理和技术检查，随所属资产交付。适用于新建环境表面、已有生成资产的 PBR 接入、表面真实感调整，以及在已有 mesh 上修复或添加图案后烘焙交付贴图。

本主文件包含完整材质流程，可按当前问题选择适用步骤。资产分件、几何创建和物理配置由 `asset-creation` 负责，资产整体外观按该 skill 验收；背景组合后的视觉问题和完整场景验收由 `scene-orchestration` 负责。材质变化涉及域随机化时，按场景或任务已确定的范围提供参数与可复现变体。

材质修改保持资产的几何外形、部件身份、运动关系和物理属性。Bump 与法线贴图只改变着色，不形成真实孔洞、缺口或碰撞起伏。需要实际几何变化时，结合 `asset-creation` 完成并复查受影响项。

工作顺序：理解目标与现有材质 → 选择来源和处理方式 → 制作与映射 → 按需要烘焙 → 绑定与导出 → 实际渲染检查 → 随资产交付。

## 2 理解目标与检查现状

以当前工作区根目录为工作目录，运行环境、资源入口和 GPU 使用约定按工作区的 `AGENTS.md` 确定。读取需求、外观参考、已有资产和有效检查记录，明确：

- 材料类别、底色、纹理方向、涂层、光泽、新旧程度，以及需要保持的设计特征。
- 表面的真实尺寸、正常观察距离和需要表现的细节；哪些变化应跨表面连续，哪些属于不同材料或独立构件的差异。
- 当前 mesh、UV、材质槽、贴图和各通道的实际连接，是否存在共享材质、重叠 UV、打包图像或外部依赖。
- 本轮调整范围、需要保留的原成果，以及最终使用的 USD 材质与渲染环境。

用户报告“不真实”时，结合实际渲染和文件检查定位。区分颜色纹理、粗糙度和法线是否存在空间变化；也检查纹理尺度、重复、硬边、光照、曝光和导出丢失等因素。材质名称、变体数量或 Blender 中存在节点，不代表交付 USD 已保留相应效果。

保留修改前的来源与参数。需要比较效果时，保存相同机位、灯光、曝光和渲染设置下的基准图。若还需要调整照明或几何，分别记录其影响，避免把整体调亮误判为材质改善。

## 3 选择材质来源与处理方式

| 当前情况 | 处理方式 |
| --- | --- |
| TRELLIS 或其他生成过程已提供可用 PBR | 接入已有材质、UV 与贴图，先检查实际效果，保留有效成果 |
| 墙面、地板、天花板等新建表面需要材质 | 按材料选用已有贴图、生图工具生成的图像、Blender 程序化节点或其组合 |
| 基础纹理可用，但表面过于均匀或机械重复 | 在原材质上调整映射，加入适量的多尺度颜色、粗糙度和法线变化 |
| 已有 mesh 上的标签、文字或局部图案不清晰 | 准备对应图像，建立局部投射或 UV 与遮罩，混合后按需要烘焙回交付贴图 |
| Blender 节点组合不能可靠保留到目标 USD 材质 | 将需要的表面通道烘焙为图像，以目标渲染器支持的材质连接交付 |

已有高质量纹理与生成成果优先复用。程序化节点可直接贡献色差、粗糙度、细微起伏和混合遮罩，也可用于映射与通道转换；不要求所有细节都先生成一张图像。复杂、有明确视觉特征的纹样按参考选择适合的图像来源，避免用简单噪声替代材料的关键纹理。

### 接入已有 PBR

保留生成单位对应的 UV、颜色、金属度、粗糙度及其他有效通道，核对通道打包方式和材质槽归属。加载源 blend 中已打包的图像，或将实际外部依赖随资产保存。

生成管线输出的 alpha 先核对其语义。已知仅用于诊断的 alpha 不直接控制资产透明度；不透明资产保持不透明，需要透明效果时按实际材料配置着色与必要几何。

### 使用生图工具制作图像

需要生成或编辑二维表面图像时使用生图工具。说明材料、配色、主方向、覆盖尺寸、细节尺度、使用方式和是否平铺。用于基色的图像采用适合映射的正视表现和均匀照明，避免透视、投影及固定高光。

需要处理生成图像的通道、平铺或遮罩时读取[生成贴图处理](references/material-preprocessing.md)；需求明确包含饮料环形残留时，原包引用的 `references/drink-ring.md` 未实际分发；此分支参考暂不可用。先取得该参考或明确独立制作依据，不把缺失资源标为已交付。

标签、文字和其他单次图案明确内容与边界；遮罩明确需要影响的区域。生成图像中的背景或棋盘格不能当作有效透明度。保留原图、提示和最终使用版本，针对明确问题编辑或处理。

## 4 材料自身的自然变化

干净、纯色的材料也可能存在轻微而连续的色差、粗糙度和细微起伏。依据材料特征、外观参考和实际观察距离决定是否增加这些变化。纯白墙、浅色漆面或同一材质的大面积铺设，不自动意味着所有位置使用完全相同的颜色、粗糙度和法线。

这类变化属于材料本身的表面表现。不要为增加真实感而擅自添加鞋印、饮料渍、钻孔、裂缝等具有明确来源或形状的局部状态；只有需求或参考需要时才制作它们。

### 按尺度组织变化

按当前材料选择有用的层次，不要求每个表面都配置固定数量的噪声节点：

| 层次 | 可表达的效果 | 调整重点 |
| --- | --- | --- |
| 大范围、缓慢的变化 | 颜料或涂层略不均匀，连续表面的局部深浅差异 | 覆盖尺度与对比度，避免显著云斑或脏污感 |
| 局部表面变化 | 加工、涂覆形成的轻微起伏和反光差异 | 变化方向、粗糙度范围、起伏尺度与强度 |
| 细小表面细节 | 颗粒、细微凹凸与表面光泽 | 与观察距离和贴图分辨率匹配，避免闪烁、锯齿和过强颗粒感 |

可以将已有纹理与不同尺度的 Noise 等程序化输出混合，分别用于颜色调制、粗糙度和 Bump。按真实尺寸确定坐标和尺度；同一个噪声数值在不同大小物体上的效果可能完全不同。

颜色调制围绕原材质底色进行，保持原有风格与材料识别特征。粗糙度在材料合理范围内变化。Bump 或法线变化从当前观察条件下合适的强度开始，通过实际渲染调整，避免把轻微表面起伏做成明显坑洼、褶皱或塑料压纹。

### 通道之间的关系

根据材料含义决定相关性：同一涂层变化可以同时影响颜色和粗糙度，但颜色深浅不自动对应表面高低。可使用部分独立的变化场，避免所有深色区域都同时凹陷并变粗糙；也不要强制各通道完全独立。

图像亮度可能来自颜料、光照或凹凸。不能将颜色亮度直接当作已知高度或法线；需要推导时说明依据、近似与适用范围，并在实际光照下检查。

### 连续性与实例差异

连续墙面或涂层的缓慢变化应按共同坐标保持连续；不同石砖、木板等构件可保留合理的个体差异。逐块换颜色或随机旋转贴图只解决部分重复问题，还需检查单块表面内部的变化。

同一花纹的偏移、旋转、比例调整遵守材料方向和真实尺度。不要把木纹方向、接缝对齐或构件加工方向随机打乱。共享材质需要实例差异时，明确哪些参数由实例提供，记录 seed 和实际采样结果。

世界坐标适合制作固定环境的连续变化；可移动资产使用所属部件的局部坐标，或将结果烘焙到 UV，保证移动、转动和开合后表面表现随部件一起运动。

## 5 映射、局部混合与通道处理

### 映射与平铺

区分可重复铺设的基底纹理、单次图案和局部遮罩。映射按真实覆盖尺寸、主方向和目标表面设置，检查拉伸、镜像、翻转及跨面连续性。

需要平铺的图像在使用的轴向上应无可见接缝；双轴平铺可用至少 2×2 的映射检查边界，并在目标面积和观察距离下检查重复感。接缝连续与大面积自然感分别判断。边缘像素数值可用于诊断，最终以实际表面渲染为准。

减少重复感可结合不同尺度的连续变化、合理的取样变化或更多源纹理。只对需要重复的图层要求平铺；独立图集或局部图案按自身边界检查。

### 局部投射与混合

在已有 mesh 上增加标签或修复局部图案时，选择适合目标表面的 UV、平面投射或其他映射，按真实尺寸放置图像，用遮罩限定影响范围。曲面上检查拉伸、侧边延伸、正反面方向及遮罩边界。

通过遮罩混合原材质与修改层。修改颜色不必同时重做全部 PBR；新覆盖层若改变粗糙度、金属度或法线响应，再处理对应通道。状态遮罩不自动成为资产的透明度，区域外保留原有材质。

新增 UV 或投射坐标可只用于制作，最终烘焙到原图集或新的交付图集。图案不必通过切割或增加独立几何实现。

### 通道语义

| 数据 | 常用解释与处理 |
| --- | --- |
| Base Color | 通常使用 sRGB 图像；颜色图中不固定记录场景照明、投影和高光 |
| Roughness、Metallic、Height、遮罩 | 作为非颜色数据读取；核对通道、范围和打包方式 |
| Normal | 作为非颜色向量数据读取；核对切线／对象空间、轴向和编码约定 |
| Alpha | 按来源确认透明、遮罩或诊断语义，按目标材质接入 |

有空间对应关系的通道保持一致的裁切、映射和变换。法线的缩放、混合或重采样按向量语义处理，不能当作普通颜色随意调色。均匀属性可以使用有依据的常数；只补充当前材料和观察需要的通道。

## 6 Blender 贴图烘焙后处理

烘焙将已有图像、局部映射和程序化节点的结果固化为交付贴图，适合在保留 mesh 的情况下修复表面或跨渲染器交付复杂材质。若现有简单材质可直接可靠导出，可沿用，不必额外烘焙。

### 6.1 确定修改范围和目标 UV

保留源网格、原材质、原图像与可复现节点。确定本次需要烘焙的通道；没有受影响的通道继续复用。相关几何与拓扑稳定后再建立最终图集。

优先评估原 UV 是否可用：局部标签修复常可烘焙回原图集；需要独立表面变化而原 UV 存在重叠，或没有可用 UV 时，可新建图集。不要为每次修改都强制重展 UV。

明确区分源取样 UV 和烘焙目标 UV。图像节点显式指定源 UV；设置实际用于烘焙的目标 UV 为活动层，并核对渲染 UV。独立图集检查非预期重叠、拉伸、图集边界和岛间留白；UDIM 或有意共享 UV 时按对应布局检查。

分辨率按表面面积、图集利用率、正常观察距离与原贴图细节决定。把大量原本重复取样的表面合并到一张独立图集，可能降低单位面积的纹理分辨率。必要时调整分组、图集布局或分辨率；颜色、粗糙度与法线不必使用相同分辨率。烘焙边缘扩张与 UV 岛间距匹配，避免接缝漏底或相邻图案串色。

### 6.2 按通道烘焙

在需要参与烘焙的各材质中建立目标 Image Texture 节点，设为活动烘焙目标；设置正确对象选择、活动对象、引擎和 UV。源图与目标图分开，避免读取正在被覆盖的目标图像。只有需要从其他几何转移表面数据时才使用相应的源到目标烘焙设置。

| 通道 | 可采用的方法 | 要点 |
| --- | --- | --- |
| 颜色 | 将最终混合颜色接到 Emission，通过 EMIT 烘焙；或使用只包含颜色的等效方式 | 不把场景灯光、阴影和高光烘焙进 Base Color |
| 粗糙度、金属度、遮罩等标量 | 将最终标量经 Emission 烘焙到非颜色图像，或使用可验证的对应通道烘焙 | 保持线性数值语义与正确通道，避免颜色空间变换 |
| 法线 | 从包含 Bump 等表面处理的材质烘焙 NORMAL，按交付需要选择切线空间等设置 | 与目标 UV、面朝向及后续渲染器约定一致，实际核对输出非恒定且方向正确 |

烘焙完成后恢复正常着色输出，以最终图像重新连接材质。将图像实际写盘或打包，重新加载后检查其内容和绑定；保存 blend 不等于所有外部图像已保存。

### 6.3 UV 与导出的一致性

Blender 进入／退出编辑模式或更改网格数据后，重新从当前 mesh 按名称取得 UV 层，再读取和导出。不要继续使用修改前持有的 UV 数据引用。本项目已发生过读取到旧取样 UV、导致烘焙图集在 USD 中出现黑块和拉伸的情况。

UV 是面角数据。按实际面的顶点顺序对应 mesh loops 与 USD 的 face-varying UV，不假定顶点数等于 UV 数。拓扑、三角化、顶点或面顺序变化后重新核对映射。单张独立图集可检查 UV 是否落在预期范围；重复纹理和 UDIM 不套用统一的 [0,1] 限制。

若目标是没有 UV 的几何基元，可结合 `asset-creation` 提供相同外形的可贴图视觉网格，保留原物理归属，避免新增重复碰撞或遗漏碰撞。视觉网格与原形体的范围、变换和可见性需核对。

## 7 USD 绑定与跨渲染器保留

使用目标渲染器支持的材质网络接入最终通道，确认实际绑定的材质、UV primvar 和贴图路径。Blender 的任意程序化节点组合不保证自动导出；需检查目标 USD 的有效连接，必要时通过烘焙保留结果。

使用 `UsdPreviewSurface` 时，颜色连接到 diffuseColor，粗糙度和金属度连接到对应标量输入。颜色图按 sRGB 解释，数据图按 raw 解释。切线空间法线输入需要 [-1,1] 的向量；若贴图以 [0,1] 编码，可在纹理读取端使用 RGB scale=2、bias=-1 解码，并核对法线方向。不能对已解码的数据再次解码。使用其他材质系统时按其约定验证。

应用正确的 MaterialBindingAPI 和材质绑定，核对对象、材质槽或面集合的归属。可移动部件的材质与 UV 随所属部件运动，局部图案不漂移到其他部件。

颜色空间、图像路径或材质连接在导出过程中可能改变。保存后重新加载最终 USD，检查有效连接和依赖解析，包含 MDL 等间接依赖。运行依赖使用交付目录内的相对路径，完整携带实际使用的贴图。

## 8 技术检查与视觉判断

技术检查与资产检查合并执行，复用仍有效的证据；修改材质、图像或依赖后，复查受影响项。图像生成、读取与证据复用沿用 `asset-creation` 的图像检查要求。Blender 预览可用于制作，最终以 Isaac Sim 加载交付 USD 的实际渲染判断。

### 技术检查

- **通道与绑定**：颜色空间、数值范围、打包通道、法线编码及材质归属正确；不透明资产没有意外透明，正常材质没有意外自发光。
- **UV 与映射**：源取样和交付 UV 对应正确，无非预期拉伸、镜像、黑块、接缝或串色，实际尺度与纹理方向合理。
- **图像有效性**：烘焙输出不是空白或意外常数，修改后图像已保存，重新加载的内容与绑定一致。
- **转换保留**：交付 USD 中存在本次需要的空间变化，不能仅依据 Blender 节点存在或文件导出成功判定通过。
- **随动与几何**：修改范围符合约定；移动或开合后贴图随部件变化。若涉及视觉几何转换，检查外形、物理归属和碰撞保留。
- **依赖与重载**：交付 USD 重新打开后依赖可解析；清理或迁移依赖后复查。

### 视觉判断

同时检查正常观察距离和能看清目标表面的近景。近景判断纹理结构、局部反光和接缝；正常距离判断材料识别、整体重复感，以及变化是否可见且自然。

检查变化是否符合参考与材料类别：纯色表面应保留底色观感；局部深浅不应意外形成污渍，细微起伏不应成为夸张坑洼，粗糙度变化不应把哑光材料变得油亮。不同材料按各自特征判断，不以“噪声更多”作为统一质量标准。

修复任务用一致机位、灯光、曝光和渲染设置比较前后。需要诊断法线或粗糙度时，可以补充更易看清反光或凹凸的视角／照明，但注明诊断用途，并回到最终场景使用条件复查。只改变展示条件的图像不作为材质改善的对照证据。

远景无改善时，先检查细节尺度、通道是否导出、纹理分辨率及照明条件，再调整强度。出现过度斑驳、失真或重复时，定位具体图层与映射修正。仍不满意的问题交回资产或场景验收，按对应修复流程处理，保留已尝试方法与未解决项。

## 9 已验证案例与适用边界

### 图书馆墙面与天花板

原项目的图书馆试验在原石材颜色纹理和天花板底色上加入不同尺度的程序化颜色调制、独立程度适当的粗糙度变化及两层 Bump，烘焙成颜色、粗糙度和切线空间法线图，在同机位、同灯光下完成 Isaac Sim 对照。用户认可第二版效果。

该案例支持：干净表面也可以通过连续、细微的材料变化改善观感；变化强度需要在实际场景中调整；独立图集可能需要更高的颜色分辨率来保留原纹理细节。案例的分组方式、噪声参数和贴图分辨率只作为实验记录，不是其他场景的固定配方。

### 胶水瓶标签修复

原项目的胶水瓶试验使用生图工具制作清晰标签，在生成的瓶身 mesh 上建立局部投射 UV 和高度遮罩，将标签混入原 Base Color，通过 EMIT 烘焙回原 UV 图集。原金属度、粗糙度及生成几何保留，导出后通过 Isaac Sim 对照检查。

该案例支持：已有生成资产可在保留 mesh 的情况下，通过局部映射、混合与烘焙完成贴图修复。正反面投射和遮罩需适配当前形体，不能直接套用瓶子的坐标或尺寸。

案例源文件与历史检查证据不随本包分发；以上结论仅说明原案例的验证范围，新资产仍须实际检查。
